# AGENTS.md

Dépôt de **connaissances Markdown en français** sur le management de projet (Scrum 2020, AgilePM/DSDM, PRINCE2 7 Foundation, PMI/CAPM, performance et tableaux de bord, analyse financière, géopolitique, leadership et changement, mégaprojets). Pas de code à compiler ni de tests à lancer.

## Règles pour les agents

- **Répondre en français**, avec les termes anglais usuels entre parenthèses.
- **Lire `INDEX.md` en premier** pour trouver le fichier pertinent dans `docs/` ; `glossaire.md` et `comparatif-methodes.md` sont des synthèses rédigées à partir des sources.
- **Citer le fichier source** (et le repère `<!-- p.N -->`, `<!-- diapo N -->` ou le n° de question).
- **Hiérarchie de fiabilité** (champ `fiabilite` du front matter) : `officiel` > `support-de-cours` > `publication` > `travail-etudiant` > `notes` > `notes-non-verifiees` / `quiz-non-verifie` ; `synthese` = fichiers rédigés à partir des sources (à vérifier dans la source citée). Signaler toute contradiction entre sources.
- **Ne pas mélanger les cadres** (Scrum, AgilePM/DSDM, PRINCE2 7, PMI) : préciser le cadre et le vocabulaire utilisés.
- **Ne pas inventer** : si l'information n'est pas dans le dépôt, le dire (et signaler « hors dépôt » toute connaissance extérieure).

## Modifier le dépôt

- Garder la structure `docs/<thème>/…` et le front matter (`titre`, `source_fichier`, `type`, `langue`, `fiabilite`, `sujets`).
- Ne pas supprimer les marqueurs `<!-- p.N -->` / `<!-- diapo N -->`.
- Ajouter tout nouveau fichier à `INDEX.md`.
- Contenu protégé (PeopleCert, APMG, PMI, SKEMA) : usage personnel d'étude.
