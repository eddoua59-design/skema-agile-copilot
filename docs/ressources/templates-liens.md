# Templates de cours — lien externe

Le dossier SKEMA/AGILE contenait un document « Lien vers des templates » qui pointe vers un **dossier Dropbox partagé par l'enseignant** (modèles de documents de gestion de projet utilisés en cours). Le contenu de ce dossier n'est **pas** inclus dans ce dépôt : il faut le demander à l'enseignant ou le retrouver dans le document d'origine « Lien vers des templates ».

> Le lien de partage Dropbox a été volontairement retiré de ce dépôt (il contient une clé d'accès).
