# SKEMA — Lecture 4 : PERFORMANCE (fonction de contrôle, objectifs, KPI et tableaux de bord)

> Cours SKEMA (support en anglais, auteur non indiqué dans le fichier) sur la performance des projets, programmes et opérations (cadre « multi-level performance »). Le PowerPoint original est très visuel et construit par animations : les diapositives successives d'un même schéma sont **fusionnées** ici et les schémas sont décrits en texte ; les références bibliographiques citées sur les diapos sont conservées.

## A. Introduction — les opérations comme organisations

- **Organisation = système finalisé (*purposeful system*)** *(Ackoff, 1971, p. 670)* : un système finalisé qui contient **au moins deux éléments finalisés**,
  - qui ont un **but commun** par rapport auquel le système a une **division fonctionnelle du travail** ;
  - dont les sous-ensembles fonctionnellement distincts peuvent **réagir au comportement les uns des autres** par l'observation ou la communication.
- Application au programme de vaccination : 5 opérations (PRODUCE, DELIVER, STORE, REGISTER, VACCINATE) = 5 systèmes finalisés ; but commun : *vacciner tous les adultes qui le souhaitent avant la fin de l'été 2021* ; division fonctionnelle du travail ; observation et communication entre opérations.

## B. Concepts clés — la fonction de contrôle

- **La fonction de contrôle comme base de la théorie du management** *(Ackoff & Emery, 1972, On Purposeful Systems, p. 31)* : elle **sélectionne les buts ainsi que les moyens** de les poursuivre (*goals* et *means / resources*).
- **Le contrôle comme source de performance** *(Ackoff, 1971)* : au moins un sous-ensemble de l'organisation a une fonction de contrôle du système :
  1. il **détermine les résultats souhaités** ;
  2. il **compare** les résultats obtenus avec les résultats souhaités ;
  3. il **ajuste le comportement du système** pour réduire les écarts observés.
- **Processus dynamique** (exemple de la production de doses) : (1) définir les résultats souhaités (buts et moyens : technologie d'inoculation, lignes de production, contrats français → millions de doses par semaine 2023-2024) ; (2) comparer (mars 2021 : 0 million de doses produites par Sanofi) ; (3) ajuster (technologie ARNm, lignes de production ARNm, contrats européens).
- **Cycle de management** : **1. Plan → 2. Do → 3. Check → 4. Adjust** (PDCA).
- **Organization agency** : les **project owners** définissent et pilotent les *objectifs et buts* de la chaîne de valeur ; les **individus et équipes projet** définissent, mettent en œuvre et livrent les *ressources* nécessaires pour atteindre les outcomes.

## C. Outil 4 — les tableaux de bord de performance

- **La performance se mesure avec des KPI et des SPECs** : mesures tangibles ; *specifications* (ex. vaccin Pfizer-BioNTech BNT162b2 « Comirnaty original » ; 250 000 doses par semaine) ; *KPI* = Key Performance Indicators.
- **Objectifs et buts SMART** *(Doran, 1981, « There's a S.M.A.R.T. way to write management's goals and objectives », Management Review, p. 36)* : **S**pecific (cibler un domaine précis d'amélioration) · **M**easurable (quantifier ou suggérer un indicateur de progrès) · **A**ssignable (préciser qui le fera) · **R**ealistic (résultats réalistes compte tenu des ressources) · **T**ime-related (préciser quand le résultat peut être atteint).
- **Objectifs et KPI** *(Kaplan & Norton, Comment utiliser le tableau de bord prospectif, p. 316)* — table Objectifs / Mesures-indicateurs / Cibles :

| Objectif | Mesure / indicateur | Cible |
|---|---|---|
| Augmenter le chiffre d'affaires | 1. Revenu par produit / service | 15 500 $ |
| | 2. Nombre de clients actifs | 483 700 |
| Augmenter le nombre de clients à forte valeur | 3. Nombre de clients supplémentaires | 215 000 |
| | 4. Profit par client | 250 000 $ |

  *But, objectif, finalité = ambitions pour le futur ; les mesures / indicateurs s'appuient sur les outcomes du système ; les cibles sont qualifiées / spécifiées par des chiffres.*
- **Exemple de tableau de bord** (production de vaccin) : processus PRODUCE (produire l'additif, produire le stabilisant, mélanger, *breakdown*, lyophiliser, conditionner) ; ressources techniques (usines, doses, contrats de précommande) et sociales (ingénieurs, chefs de ligne) :

| Objectif | Indicateurs | Cibles |
|---|---|---|
| Augmenter les doses de vaccin ARNm produites dans les pays de l'UE pour les pays de l'UE | Doses par semaine / usine (1er trimestre 2021) | 1 million |
| | Doses par semaine / usine (2e trimestre 2021) | 2 millions |

  Puis un tableau **Ressources / Spécifications / Quantité** (vaccin covid-19, usines, contrats de précommande, ingénieurs, chefs de ligne).

**Workshops** : (1) chaque membre travaille sur un système opérationnel pour concevoir un **tableau de bord du résultat de l'opération (GOAL)** : définir le(s) objectif(s) clé(s), identifier les mesures de performance, proposer des cibles SMART ; (2) concevoir un tableau de bord des **ressources requises (MEANS)** : suggérer les spécifications pertinentes (la fonction « ressource → processus → output » doit permettre d'atteindre les objectifs) ; pour chacune des 5 ressources, préparer une slide (description des spécifications, chiffres et sources).
